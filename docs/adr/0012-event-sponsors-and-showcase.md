# Event sponsors, layered brackets and staff showcase

Event overview and individual match pages may show a small dismissible message from active event sponsors. Messages have a 35% chance, a five-minute session cooldown and a twelve-second duration.

Brackets display all published rounds by default and connect explicit feeder references, retaining team tracing, round focus and zoom. Calendar helper text and redundant source captions are removed. Tournament catalogue cards use a compact horizontal layout.

An idempotent fictional staff showcase seeds sixteen teams, fourteen matches, two divisions, venue information, announcements, sponsors and roster review examples. Subsequent seeds preserve edits. Existing access controls apply, with no migration or new environment variables.

Discovery explores tournaments in a keyboard-focusable swipe carousel. Catalogue artwork remains a short horizontal header. Demo clocks still drive schedule calculations but their public banner is omitted. Large desktop backgrounds show two of five volleyballs (half rounded down); smaller screens retain five. Two additional live exhibition fixtures are appended idempotently without changing edited matches or playoff results.

Sponsor popups now appear on every second eligible page entry per event and browser session, replacing random probability and cooldown. Venue information is grouped into four compact expandable resource cards, and event partners use a carousel. Red Bull is explicitly a fictional demo placement. Team following uses a searchable paginated checkbox dropdown retaining division follows. Rankings sum published set points from completed matches, grouped by division with ties sharing rank; they are not an official competition standings calculation. Saved-event bell counts refresh every thirty seconds while the app is open. Public role labels use Lead while existing role identifiers and permissions remain stable.

Bracket control captions are visually hidden while accessible names remain; saved teams use the same stable colour marker in the profile, team picker and bracket.
